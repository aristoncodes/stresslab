# Max Subarray Sum, multi-test

## Input
The first line contains t (1 <= t <= 10^4), the number of test cases.
Each test case: a line with n (1 <= n <= 2*10^5), then a line with n integers a_i (-10^9 <= a_i <= 10^9).

## Output
For each test case print the maximum sum of a non-empty contiguous subarray.
